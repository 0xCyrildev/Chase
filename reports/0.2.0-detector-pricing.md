## What the two bold rows are

Both are the same bug class, caught by pricing rather than by reading the code: a new
low-severity detector **corroborating** an existing finding and thereby raising someone
else's priority.

- **C6, P3→P2 on 4 transactions.** `COIN_NET_IMBALANCE` is the same `balanceChanges` array
  the per-address rule reads, summed. It also co-occurs with the routing patterns that
  produce it. Remedy: join it to the swap-shape cluster in `EXPECTED_OVERLAP` — one opinion
  about one construct.
- **C7, P3→P2 on 2 transactions.** `DYNAMIC_FIELD_CREATED` is genuinely orthogonal to a
  routing pattern, so an overlap pair would have been a false statement about the construct.
  It fires on 2% of all traffic, which makes it a poor *witness* even though it is an
  interesting *fact*. Remedy: a distinct mechanism — `corroborates: false` on the emission,
  meaning reported and never used to escalate.

The distinction is the point of the second fix. "Same construct" and "too noisy to count" are
different claims, and before 0.2.0 the only available table could express the first.

## Rates each new detector shipped with

Measured on the 6,502-trace corpus, per transaction:

| Type | Rate | Note |
|---|---|---|
| `COIN_NET_IMBALANCE` | 189 txs (2.91%) | 71.59% with `0x2::sui::SUI` included; 4,466 of those are gas alone — the exclusion is load-bearing |
| `DYNAMIC_FIELD_CREATED` | 128 (1.97%) | mutation would be 3,807 (58.55%) and is deliberately not a rule |
| `DYNAMIC_FIELD_DELETED` | 58 (0.89%) | 16 transactions do both, so the pair is suppressed against itself |
| `UNANNOUNCED_OBJECT_CHANGE` | 38 (0.58%) | the wide "emitted no events" shape is 588 (9.04%), and 39.14% of all traffic emits nothing |
| `ADDRESS_OUTFLOW` (pre-existing) | 122 (1.88%) | the field-test narrative that it fires on "essentially every swap" did not hold on this corpus |

Also measured and deliberately not built: widening `CAP_PATTERNS` to a `*Cap` suffix family.
416 cap-shaped object changes across 414 transactions are outside the current list, and none
of them was transferred to a different address or left the sender's ownership — the widening
would have added no finding on this corpus, so it is coverage that cannot be priced.
